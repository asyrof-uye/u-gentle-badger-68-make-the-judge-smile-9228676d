## The entry

One line, 146 characters, about a small good thing that happened today:

> At 7 a.m. the baker slipped an extra warm roll into my bag and whispered, 'on the house — you look like you could use a win' — and, reader, I did.

## How it works

`main.ts` writes the line to `/output/entry.txt` (or `$OUTPUT_DIR/entry.txt`
locally). It self-checks the house gate first — UTF-8 text of 1 to 200
characters, not only white space — and verifies the write by reading the file
back byte for byte.

```sh
node main.ts
```
